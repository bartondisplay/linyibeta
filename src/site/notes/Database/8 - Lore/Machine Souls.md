# Machine Souls

Machine Souls are manufactured entities from pre-scream times. Their conciousness, contained in a [[Database/8 - Lore/Machine Souls#Quantum Cores\|quantum core]], can be either bound or unbound - destined to perform certain tasks or to live as a free artificial soul. No known machine souls exists in the Linyi Beta sector and knowledge of these entities comes solely from historic texts. 
## Quantum Cores

The hypothesis is that a machine soul is essentially its *quantum memory core*. Artefacts have been found, roughly the size of a man’s fist, appearing to be a transparent, diamond-like stone. The fabrication of an actual memory core is calculated to be a heroic effort of science beyond the capacity of the core worlds. These cores would provide the basic cognitive and memory functions for the machine soul's mind. Without being attached to additional sensory and processing hardware, the soul lies “dreaming” within its core, unable to perceive or influence the external world.
